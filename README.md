### Cześć, tu Michał P. Dudek 👋

Tworzę hobbystycznie edukacyjne aplikacje mobilne na system Android w języku Kotlin (Jetpack Compose).

#### ⚓ Flagowy projekt
- **Sternik - symulator FPV** *(Aplikacja szkoleniowa, wersja 3.0)*  
  Edukacyjny symulator żeglugi śródlądowej z widoku dziobu łodzi: **128 losowych sytuacji** (dzień, mgła, żegluga nocna, śluzy, mosty, ratownictwo), **73 wektorowe znaki i pławy** (w tym znaki kardynalne N, E, S, W), **Kompendium (81 pozycji)** oraz **Quiz wiedzy** zgodne z Ustawą z 21.12.2000 r. oraz Rozporządzeniem MI z 28.04.2003 r.  
  🌐 Strona aplikacji: https://mickanovi.github.io/
